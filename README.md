# Kashan Sohrab - Portfolio

Static site: no install, no build step.

Run it in VS Code:
1. Unzip and open the folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension, right-click index.html > "Open with Live Server".
   (Or just double-click index.html to open it in a browser.)

Edit content in index.html. Colors are the variables at the top of css/style.css.
Fonts load from Google Fonts when online; system fonts are used as fallback offline.
